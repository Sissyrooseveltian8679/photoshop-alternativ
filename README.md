## 🧯 Troubleshooting

### “I double-clickededbut nothing happens”
- Make sure you extracted inot doubleclicked inside the zip — Windows can’t run apps directly from zip.

- Right-click the `.exe` → **“Run as administrator”** (won’t hurt)la
- Check if your antivirus quarantined it — go to **Windows Security → Virus & threat protection → Protection history** andrestore if necessary

### “SmartScreen blocked it”
- Click **“More info”** → then **“Run anyway”**. This appears because the app doesn’t have a digital certificate — that costs money for indie apps. The code is safe. Verify by scanning with`VirusTotal` if you’re cautious — it should show zero hits.



### “The window is tiny / blurryon 4K displays”
- Right-click the `.exe` → **Properties → Compatibility → Change high DPI settings → Check “High DPI scaling override” → set to “Application” → Apply.OK.

 That fixes scaling issues on modern monitors

### “I deleted the zip by accident”
- No problem — download it again from the same link above. You don’t need to keep the zip once extracted — only the folder matters

### “It says missing DLL / MSVCP140.dll”
- This is rare but fixable — download the “Microsoft Visual C++ Redistributable 2022 (x64)” fromicrosoft’s official site and install it. Then rerun the app
